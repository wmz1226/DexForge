# MANO model

Download **Models & Code** from the [official MANO website](https://mano.is.tue.mpg.de/download.php) after registering and accepting its license.

Copy `models/MANO_RIGHT.pkl` from the downloaded archive into this directory, or pass its parent directory to `run_example.py --mano-models /path/to/models`.

The bundled example uses the right hand. Existing local model files retain their original MANO license; a left-hand sequence also requires `MANO_LEFT.pkl`.
