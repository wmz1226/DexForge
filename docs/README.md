# DexForge project website

Static project page for DexForge. Retargeting Result contains ContactAware and ForceAware, followed by a separate real-world demonstration section. The code link points to the retargeting implementation in this repository.

No build step or external dependencies are required. Preview from the repository root with `python -m http.server 8000`, then open `http://localhost:8000/docs/`.

To publish, open repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/docs**, and save. The site address is https://wmz1226.github.io/DexForge/.

Select a hand to browse results. Click a video for the high-resolution view; press Escape to close it. Expand opens a panorama with pan and zoom. Playback respects reduced-motion preferences.

The ContactAware and ForceAware galleries are curated independently. These qualitative examples are not an aggregate success-rate evaluation. Videos retain their source timing; the panoramas use 15 fps and loop shorter clips at their original speed. Real-world previews use 720p and enlarged views use 1080p.
